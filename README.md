# 📚 BookConnect

BookConnect é um **protótipo de alta fidelidade** de uma rede social com
foco em livros, inspirado em plataformas como **Skoob** e
**Goodreads**.\
O projeto foi desenvolvido como **segunda avaliação da disciplina de
Interação Humano-Computador (IHC)**, com o objetivo de aplicar conceitos
de usabilidade, design centrado no usuário e prototipação de interfaces.

------------------------------------------------------------------------

## 🎯 Objetivo do Projeto

Criar um protótipo de uma rede social voltada para leitores, permitindo
a interação entre usuários por meio de livros, avaliações e organização
de leituras, atendendo aos requisitos definidos em sala de aula.

## 🖥️ Telas do Protótipo (Alta Fidelidade)

O protótipo contempla, no mínimo, as seguintes telas:

- Tela Inicial (Início); 
- Descobrir, com navegação por categorias; 
- Minhas Listas; 
- Clubes; 
- Clubes de Leitura; 
- Perfil do Usuário; 
- Perfil do Livro.
